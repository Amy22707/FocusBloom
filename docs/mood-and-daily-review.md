# 心情与每日复盘

日期：2026年10月16日

## 记录与补记

左侧“心情与复盘”提供独立月历，默认查看今天。点击日期查看记录与当天投入，使用日期选择器的年／月列表或前后月份按钮跳转。过去日期可补记、编辑，未来日期不能记录。

每天保留一条心情与复盘，支持五种心情、自由标签、今天的感受、想记住的事、明天的第一步。选择心情即可保存，文字可留空；也可不选心情，只写复盘。标签用逗号分隔，保存时整理空格并合并重复项。

编辑后保留原日期与页面位置。同一天再次保存会更新已有记录。删除需确认，只删除当天心情与复盘，专注、待办、习惯及成果记录继续保留。

## 月历与趋势

月历用表情和轻柔色块展示已记录心情，只写复盘的日期显示“记”。当前日期与选中日期分别描边，未来日期仅查看。颜色跟随深浅主题调整；布局较窄时，日期详情移动到月历与趋势下方。

趋势按当前月份展示已记录心情，只连接连续日期，未记录日期保留空白，不补成低分或平均值。点击圆点可查看当天记录。月份摘要显示记录天数及较常出现的心情。

设置中的“事项块大小 → 心情月历”可调整日期块大小；详细汇总的折叠状态会保存。栏目加入导航显示开关与排序，默认位于设置前。

## 当天投入与完成

当天有效专注时间按实际区间拆分，排除暂停和休息，专注次数及成果按会话结束日归属。显示当天实际完成的待办、习惯打卡／计划数量，并可展开查看完成事项及专注成果。

待办完成时间从本版本开始记录：首次设为已完成时保存时间，修改名称或备注保留时间，撤销完成时清除，再次完成记录新时间。旧待办没有完成日期的，不推定到某一天。习惯历史汇总按当前计划及已有打卡记录计算。

自动汇总随专注保存、待办状态和习惯打卡更新，不需要另填一次；记录或查看复盘不会改变当前计时项目、暂停计时或自动结束专注。

## 每日提醒

页面右上角可设置每日提醒，默认关闭，默认时间21:00。当天已经记录心情或复盘后取消该日提醒。提醒受软件提醒总开关控制，通过现有Windows计划通知服务续排未来30天；点击提醒进入对应日期。

通知只显示记录提示，不包含个人心情、标签或复盘正文。本模块本地保存，不导入现有任务／专注日历，也不写入ICS或Outlook同步。

## 数据

`daily_reflections`按日期唯一保存心情与复盘JSON；`todo_items.completed_at`保存待办最近一次完成时间。提醒偏好为`reflection.reminder`，汇总展开偏好为`reflection.summary.expanded`。本地数据库备份包含这些数据。
