# 桌面组件

日期：2026年10月17日

## 开启与设置

进入“偏好设置 → 桌面浮窗与组件”，勾选专注时长、待办列表、日期事项、习惯打卡、心情月历或日历与课表。各类组件默认关闭，可独立启用。原来的计时浮窗继续单独使用。

组件顶部左侧可拖动，边缘可调整大小。鼠标移入后，右上角显示打开主界面、组件设置和关闭按钮。关闭组件仅关闭显示，原始数据与展示偏好保留。

每个组件的设置可选择视图、背景、置顶和透明度，并通过滑块调整尺寸。背景可跟随软件主题、选择色板或输入颜色代码，也可选择本地图片；图片自动搭配深色遮罩，文字随背景调整明暗。位置、尺寸、所在显示器及开关状态保存，重开后恢复；恢复时将窗口放入可用工作区。主窗口进入托盘或最小化后，组件仍显示。退出软件时一起关闭。

## 视图与操作

| 组件 | 视图 | 使用 |
| --- | --- | --- |
| 专注时长 | 数字、趋势、热力图 | 日／周／月／年，全部或指定项目；点击右上角打开对应专注统计 |
| 待办列表 | 平铺、紧凑列表、按截止日期、四象限 | 全部或指定待办文件夹；直接勾选完成，点击名称查看详情，＋添加事项 |
| 日期事项 | 卡片、列表、大字、月历 | 全部或勾选指定事项，可显示封面；大字视图前后切换，月历按实际发生日期展示重复事项 |
| 习惯打卡 | 列表、平铺 | 全部或勾选指定习惯，当天直接打卡；撤销前确认，点击名称查看历史或补打卡 |
| 心情月历 | 月历、趋势 | 点击日期记录、编辑或补记，未来日期不能记录；使用原有心情与复盘弹窗 |
| 日历与课表 | 日、周、月、年、课程表 | 前后切换日期，年月列表跳转，月历与年历点日期展开；点击事项打开原有详情 |

### 专注时长

共用原始专注区间与当前计时，排除暂停和休息，包含睡眠期间按现有计时规则累计的投入。跨日按实际区间拆分。进行中的投入标为“尚未保存”，结束保存后使用同一记录ID去重；不足10秒结束时按既有规则不计入记录，临时显示随之撤回。专注次数仅显示已经保存的场次。

数字每秒更新，图表按数据变化或分钟刷新；已保存记录的汇总缓存复用，日常计时刷新不持续读取数据库。

### 待办与日期事项

待办组件的文件夹与主界面选中位置分别保存。直接勾选完成不切换主界面的当前文件夹或计时项目；勾选“显示已完成”后，完成事项仍排在最后。按截止日期显示时，先按日期列出有截止日期的未完成事项，再列无截止日期事项。平铺的列数跟随宽度，四象限按重要／紧急属性分组，各象限可直接添加。

日期事项使用现有倒数日／正数日、循环与置顶顺序。卡片可显示异步加载的封面，大字视图展示单项，月历可通过年月日期选择器跳转；有多项的日期可选择要打开的事项。点击事项进入原有详情与编辑流程。

### 习惯与心情

习惯遵循现有计划执行日及补打卡规则，打卡同步更新主界面目标、连续完成情况与相关统计。心情月历沿用主界面的表情和配色，趋势不为未记录日期补值，只连接连续的已记录日期。

### 日历与课表

日／周／月／年展示带截止日期的待办、日期事项及待办安排，课程只在“课程表”中显示。课程按周展示，沿用学期、单双周、多次上课和调停课规则；周视图和课程表可横向滚动查看七天。月历选择日期后在下方列出当天事项，年历点击日期进入日视图。组件日期与视图独立于主界面，点击右上角打开主界面时带入当前位置。

## 数据与生命周期

配置保存在`widgets.Focus`、`widgets.Todos`、`widgets.Dates`、`widgets.Habits`、`widgets.Mood`和`widgets.Calendar`，不另存业务记录。各组件独立于主窗口，按业务变更刷新数据；所有组件关闭后停止组件刷新定时器。退出时统一关闭窗口并解除事件，保留启用状态。

Windows会话结束时通过[WPF SessionEnding](https://learn.microsoft.com/en-us/dotnet/api/system.windows.application.sessionending?view=windowsdesktop-10.0)处理组件关闭和偏好保存。
