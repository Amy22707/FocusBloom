# 专注图文与声音

日期：2026年10月10日

桌面专注页显示项目、计时、状态、背景图与一句文字。普通窗口和全屏共用同一会话、图文与声音播放器。

在“偏好设置 → 专注字体”中，中文、英文和计时数字分别以示例卡片选择，修改即时应用并在本机保存，重开后恢复。中文提供微软雅黑、等线、宋体、楷体与仿宋；英文提供 Segoe UI、Calibri、Arial、Georgia、Cambria、Verdana；计时数字提供简洁、工业机械、机械刻字、窄体仪表、终端等宽、控制台和打字机风格，对应 Segoe UI、Bahnschrift、OCR A Extended、Agency FB、Consolas、Lucida Console、Courier New、Arial。只显示本机已安装的候选字体，也可一键恢复默认。

默认中文为微软雅黑，英文与计时数字为 Segoe UI。中英文混排采用各自选择的字体；数字保持轻字重与等宽数字排布。普通页、全屏页及素材文字卡片同步应用，切换字体不更换当前图文或计时状态。

句子在普通页与全屏页适度放大。开始／暂停／继续／结束集中显示；常亮按钮位于底部左侧，声音面板入口位于右侧；两者按钮尺寸接近主要操作、略小一档，图片来源使用低调文字显示。学习浏览器入口位于顶部，图文素材在偏好设置中管理。

## 使用

1. 选择项目、计时方式与专注模式，开始专注。每次新专注选取一张背景与一句文字；暂停／继续、切换全屏、学习浏览器、主题和从托盘恢复均保持本次内容。
2. 在“偏好设置 → 专注图文与声音”背景、文字、声音区域默认折叠，只显示当前选择；点击区域标题展开卡片，再点击“使用”，也可再次收起。背景和文字可选择每次随机，背景还可选择纯色；专注中的图文选择在下一次采用。
3. 三种素材都支持收藏、删除和“只看收藏”。背景和文字提供“随机时只选收藏”；背景还可排除随机候选。没有可用图片时使用主题背景，没有可用句子时不显示文字，计时正常继续。
4. 添加自己的图片或本地图片文件夹。文件夹读取其中的图片，启动及开始新专注时加入新图片。个人图片以本机路径保存，移动或删除后可重新添加。
5. 在文字区域展开“添加文字或摘录”，填写作者、作品、译者与来源；已有个人摘录可从卡片编辑。导入 `.txt` 时每行作为一句，之后可补充出处。

选择、收藏和删除状态保存在本机，重开后恢复。删除仅从素材库移除，不删除本地图片或音频文件；默认素材可通过各区域的“恢复默认”重新加入，已移除的文件夹图片不会自动重新出现。专注中删除当前背景或句子仍保持本次显示，下一次更新；删除当前音源停止播放。

多个随机候选时避免连续两次选择相同图片或句子；新专注独立选取，当前会话不轮播。

## 声音

点击普通页或全屏页右下角的“声音”，从列表直接选择音源，收藏的音源优先显示，控制播放／暂停、音量与静音；偏好设置展开后的声音区域提供完整素材卡片。支持本地 MP3、WAV、M4A、AAC、WMA、FLAC、AIFF，具体解码由 Windows 与 NAudio 提供。

计时暂停不自动暂停声音，切换全屏或返回普通页继续同一播放。音频循环时将末尾与开头交叉淡化；音源可在专注中切换。软件重开恢复音源、音量及静音偏好，播放由用户启动。

可开启专注／休息结束提示音。提示遵循声音音量与静音状态；计时和限制解除不等待提示音播放。

## 默认素材

- 首批6张背景来自 Pexels，包括湖光、森林、海岸、瀑布、薄雾与远海，随发布目录离线提供。
- 默认25句采用功能文档提供的原文；个人摘录保存其填写的出处。
- 轻雨与壁炉为 CC0 环境录音；白、粉红、棕噪音为合成音源，名称明确区分。
- 专注与休息提示为原创合成音。

图片来源按钮显示作者和授权，并可打开原始页面；音源来源入口在图文设置中。完整来源见 `src/FocusBloom.Desktop/Resources/Focus/catalog.json` 与 `SOURCES.md`。[Pexels 授权](https://www.pexels.com/license/) · [雨声来源](https://opengameart.org/content/rain-loopable) · [壁炉来源](https://opengameart.org/content/fireplace-sound-loop)
