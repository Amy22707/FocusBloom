# 专注图文与声音

日期：2026年10月12日

桌面专注页显示项目、计时、状态、背景图与一句文字。普通窗口和全屏共用同一会话、图文与声音播放器。

图片采用约42%不透明度的暗色遮罩，保留背景颜色与细节，并配合白色计时和文字；普通页与全屏保持一致。

在“偏好设置 → 专注字体”中，中文、英文和计时数字分别以示例卡片选择，修改即时应用并在本机保存，重开后恢复。中文提供微软雅黑、等线、宋体、楷体与仿宋；英文提供 Segoe UI、Calibri、Arial、Georgia、Cambria、Verdana；计时数字提供简洁、工业机械、机械刻字、窄体仪表、终端等宽、控制台和打字机风格，对应 Segoe UI、Bahnschrift、OCR A Extended、Agency FB、Consolas、Lucida Console、Courier New、Arial。只显示本机已安装的候选字体，也可一键恢复默认。

默认中文为微软雅黑，英文与计时数字为 Segoe UI。中英文混排采用各自选择的字体；数字保持轻字重与等宽数字排布。普通页、全屏页及素材文字卡片同步应用，切换字体不更换当前图文或计时状态。

深浅模式同步列表背景、文字、选中状态与滚动区域；Windows 11 的系统标题栏也采用软件主题的背景和文字颜色，切换外观或退出全屏后更新。

句子在普通页与全屏页适度放大。开始／暂停／继续／结束集中显示；常亮按钮位于底部左侧，声音面板入口位于右侧；两者按钮尺寸接近主要操作、略小一档，图片来源使用低调文字显示。学习浏览器入口位于顶部，“返回窗口”位于全屏页最右侧，图文素材在偏好设置中管理。

## 使用

1. 选择项目、计时方式与专注模式，开始专注。每次新专注选取一张背景与一句文字；暂停／继续、切换全屏、学习浏览器、主题和从托盘恢复均保持本次内容。
2. 在“偏好设置 → 专注图文与声音”背景、文字、声音区域默认折叠，只显示当前选择；点击区域标题展开卡片，再点击“使用”，也可再次收起。背景和文字可选择每次随机，背景还可选择纯色；专注中的图文选择在下一次采用。
3. 三种素材都支持收藏和“只看收藏”。默认图片、文字和声音不可删除，自定义素材删除前弹出确认。背景和文字提供“随机时只选收藏”与“不参与随机”；被排除的素材仍可手动固定选择。没有可用图片时使用主题背景，没有可用句子时不显示文字，计时正常继续。

背景、文字和声音素材区由整个设置页面统一滚动，卡片最后一行可完整查看；文字和声音每行三张。收藏和筛选文字、复选框边框及勾选状态跟随主题。

背景卡片先显示名称和操作，缩略图在后台分批加载，等待时显示“加载图片…”。同一素材的缩略图在本次运行中缓存，再次展开不重复读取；无法读取的图片显示“图片不可用”。

视频卡片通过Windows缩略图功能在后台提取一帧，显示静态画面和小型播放标记，加载时显示“加载视频预览…”。每次运行复用已加载的画面，不在列表中播放视频或发出声音；无法提取时显示“视频预览不可用”，视频仍可选择并尝试播放。

4. 添加自己的图片、GIF 动图或本地图片文件夹。GIF 在普通／全屏专注页循环播放，素材卡片显示静态缩略图与“GIF 动态”标记，也支持收藏、删除、固定和随机选择。文件夹读取其中的图片与 GIF，启动及开始新专注时加入新素材。个人图片以本机路径保存，移动或删除后可重新添加。
5. 在文字区域展开“添加文字或摘录”，填写正文、作者、作品、译者、来源及出处说明；自定义句子可从卡片点击“编辑”，默认句子不可编辑。保存或取消编辑后回到原卡片位置；保存后重开仍保留修改，正在进行的专注保持原句。导入 `.txt` 时每行作为一句，之后可补充出处。

素材卡片分别标记“默认”与“自定义”，文字卡片使用相同的作者／作品／译者格式，显示出处说明，来源为网页时提供“出处”按钮。英文作品名使用斜体。文字区域的“恢复默认”重新读取随包句子，保留自定义句子、收藏和不参与随机设置。

选择、收藏和删除状态保存在本机，重开后恢复。删除仅从素材库移除，不删除本地图片或音频文件；默认素材始终保留，已删除的自定义文件夹图片不会自动重新出现。专注中删除当前背景或句子仍保持本次显示，下一次更新；删除当前音源停止播放。

多个随机候选时避免连续两次选择相同图片或句子；新专注独立选取，当前会话不轮播。

GIF 动画在专注和暂停时持续播放，切换全屏保持同一素材；离开专注页、进入学习浏览器或隐藏到托盘时释放播放资源，返回后重新播放同一 GIF。卡片仅显示缩略图。若动画无法播放，显示静态背景并提示重新选择。

使用“添加背景”导入本地 MP4 或 WMV，也可通过文件夹加入。视频卡片标记“视频循环”，提供收藏、删除、固定与随机选择。普通与全屏专注页自动循环，计时暂停期间继续播放；离开页面或隐藏窗口时关闭播放器，返回后重播同一视频。背景视频默认静音，与声音面板独立。当前专注中改选素材仍在下一次采用。

视频使用 Windows 媒体解码，MP4 可采用 H.264 编码；无法播放时回到主题背景并显示提示。清晰度与流畅度取决于源文件分辨率和帧率。默认视频“林溪流光”为1920×1080、约29.97帧/秒，背景库不再提供低帧率瀑布 GIF。

有效专注时长不足10秒的会话结束后提示“本次专注未计入”，不保存到专注记录、不计入统计时长；暂停时间不计入有效时长，满10秒正常记录。退出软件结束的短会话同样不保存，退出时不弹窗。

## 声音

点击普通页或全屏页右下角的“声音”，从列表直接选择音源，收藏的音源优先显示，控制播放／暂停、音量与静音；偏好设置展开后的声音区域提供完整素材卡片。支持本地 MP3、WAV、M4A、AAC、WMA、FLAC、AIFF，具体解码由 Windows 与 NAudio 提供。

声音弹窗使用连续像素滚动，列表行紧凑排列，最后一项可完整滚入视口，底部没有额外空行。普通与全屏页使用同一控件。

计时暂停不自动暂停声音，切换全屏或返回普通页继续同一播放。音频循环时将末尾与开头交叉淡化；音源可在专注中切换。软件重开恢复音源、音量及静音偏好，播放由用户启动。

可开启专注／休息结束提示音。提示遵循声音音量与静音状态；计时和限制解除不等待提示音播放。

## 默认素材

- 首批6张背景来自 Pexels，包括湖光、森林、海岸、瀑布、薄雾与远海，随发布目录离线提供。
- 默认动态背景“林溪流光”为 BLM Oregon & Washington 的1080p视频，采用 CC BY 2.0，离线随包提供，可收藏、固定选择或不参与随机。
- 默认25句采用用户手工修改并确认的正文、署名与作品名；无法独立确认的五项归属按用户决定沿用，核对状态记录在文档。资料见 [默认句子出处](quote-sources.md)。个人摘录保存其填写的出处。
- 轻雨与壁炉为 CC0 环境录音；白、粉红、棕噪音为合成音源，名称明确区分。
- 专注与休息提示为原创合成音。

图片来源按钮显示作者和授权，并可打开原始页面；音源来源入口在图文设置中。完整来源见 `src/FocusBloom.Desktop/Resources/Focus/catalog.json` 与 `SOURCES.md`。[Pexels 授权](https://www.pexels.com/license/) · [雨声来源](https://opengameart.org/content/rain-loopable) · [壁炉来源](https://opengameart.org/content/fireplace-sound-loop)

## 当前边界

默认背景库包含6张静态图片与1段1080p视频，海浪与鸟鸣录音可继续补充；在线背景库后续接入。个人素材以文件引用使用，不自动上传。不同输出设备的听感、音量和循环衔接继续结合实际使用调整。

账号与云同步后续实现，保留已确认的插件登录后与桌面同步数据需求。浏览器独立插件当前的界面与素材能力见 `docs/browser-extension.md`。
