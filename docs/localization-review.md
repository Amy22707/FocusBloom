# 语言检查

界面语言默认为简体中文。在「语言/Language」保存 English 后，重新打开软件应用。

## 已覆盖

固定界面标签、计划本、计时设置、默认背景与音频名称、心情名称、目标周期与完成状态、习惯执行日与连续天数、统计筛选、卡片缩放预览、排序菜单、桌面组件设置选项和统计周期比较支持中英文。

用户创建的名称、日记、摘录、来源署名和内容中的单位保留原文。筛选值与本机存储使用原有标识。

## 验证

独立资料与后台桌面验证覆盖全部主页面的默认状态、英文目标与单位、统计筛选、计划本历史和草稿、从计划事项开始专注、截图导出及五秒提示。固定资源还检查了中英文格式占位符的一致性。

## 待完成

桌面组件的部分日期、课程与调课的动态描述、部分统计图表提示、系统提醒摘要及异常分支仍有中文拼接文字。完整英语版本需补齐这些分支后再验收。应用进入默认页面的检查不能替代这些分支的操作验证。
