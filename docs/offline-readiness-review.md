# 离线版验收状态

Windows x64 核心功能、独立计划本、应用限制、主题设置、文件备份和截图导出已实现。MSI 安装包按当前 Windows 用户安装，提供开始菜单入口。

## 已完成的检查

独立资料与后台桌面检查覆盖计时、计划本历史、勾选、事项级专注记录重开、资料库升级、恢复和本机导入。浏览器扩展在独立 Chrome、Edge 和 Firefox 配置中验证计时、外观与网站限制。

## 仍需完成的验收

- 全部英文动态提示的逐分支验收，具体范围见[语言检查](localization-review.md)。
- 不同权限应用、独占全屏、多屏、休眠后的实际限制与通知行为。
- 安装包签名，需要发布者的代码签名证书。
- 自动下载和安装更新。
- 扩展商店提交与审核，需要开发者账户及图标分发授权。
