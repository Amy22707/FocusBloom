# 独立浏览器扩展

日期：2026年10月24日

一刻专注浏览器版可独立在 Chrome、Edge 和 Firefox 桌面版中运行，提供专注计时和网站黑白名单。规则与计时保存在当前浏览器配置中。

## 安装

1. 使用 `artifacts/FocusBloom-browser-extension.zip`，解压到固定目录；开发工作区也可直接使用 `artifacts/browser-extension` 或 `extensions/browser`。
2. Edge 打开 `edge://extensions`，Chrome 打开 `chrome://extensions`，开启开发人员模式。
3. 选择“加载解压缩的扩展”，选择包含 `manifest.json` 的文件夹。
4. 将一刻专注固定到浏览器工具栏，点击图标，设置网站规则并开始专注。

扩展图标不随仓库分发；从源码加载前需将`16.png`、`48.png`、`128.png`放入`extensions/browser/icons/`。

无需桌面软件、.NET、Native Host 或注册脚本。更新同一安装目录后，在扩展页面点击“重新加载”；保留同一浏览器配置和扩展 ID 以继续使用本地数据。

Firefox 测试使用独立 Firefox 包，打开 `about:debugging#/runtime/this-firefox`，选择「临时载入附加组件」，选中 Firefox ZIP。临时加载在浏览器关闭后失效。商店分发见[商店提交说明](extension-store.md)。

## 网站规则

| 模式 | 行为 | 空列表 |
| --- | --- | --- |
| 白名单 | 仅允许列表内的网站 | 普通网站全部受限 |
| 黑名单 | 仅限制列表内的网站 | 不限制网站 |

两种列表分别保存。输入域名或 http／https 网址，选择是否包含子域名。支持添加、编辑、删除，以及从工具栏面板添加当前网站。

“限制网站”开关决定本次是否拦截网页。开启后，专注与暂停期间使用开始时的模式与列表快照；休息／结束时解除。专注中不能编辑列表，结束或休息时可修改，新规则在下次专注采用。

已有受限标签页和新访问进入阻止页，暂停保持限制。关闭网站限制、进入休息或结束后恢复原网址。页面所需图片、脚本、样式、接口和已有下载保持正常；规则只处理顶层 http／https 网页。

## 计时与专注页

工具栏面板提供“专注计时／网站规则／记录／偏好设置”四个入口，默认突出计时、状态与开始／暂停操作。计时卡片的“调整”和顶部设置按钮进入计时安排，返回专注后直接采用本次填写的安排；保存默认偏好可在下次继续使用。

独立专注页沿用桌面版的左侧导航、内容标题和圆角卡片。窄窗口将导航移至顶部；面板及专注页共用与桌面版相同的6种配色及明暗主题。名单单独管理，空列表会说明对应限制行为；计时期间仍可查看设置，受限的编辑项保持禁用。

- 正计时从零累计，可手动结束；累计有效专注达到24小时后自动结束并保留本次时长，解除网站限制，不进入休息。下次打开面板或重新聚焦专注页时提示一次。
- 倒计时可设10秒至24小时，到点结束，也可提前结束。暂停与休息参数均最多1440分钟。
- 提前结束时有效专注不足10秒，标记为未计入；暂停与休息不算有效专注，满10秒正常计入。倒计时不足10秒时不能开始或保存偏好。
- 暂停不计入有效专注，默认5分钟，可调整，到点自动继续或主动继续。
- 可选休息，时长为零时直接结束；休息期间不限网站，可跳过。
- 计时方式、时长、本次专注名称可保存为默认偏好；开始时也保存当前选择。
- 关闭面板后继续计时。浏览器重开后从保存的真实时间点恢复，关闭浏览器或电脑睡眠的时间遵循当前专注／暂停区间计入。
- “打开专注页”提供浏览器标签页中的完整界面，支持全屏与退出全屏；与工具栏面板显示同一会话。
- 提供 12 种配色，明暗支持浅色、深色和跟随系统，默认跟随系统，偏好保存在当前浏览器中。

扩展与桌面软件独立计时、独立保存规则。插件只控制所在浏览器中的网站；Windows 应用限制仍由桌面软件负责。桌面严格模式中使用外部浏览器时，仍需按桌面的应用黑白名单放行该浏览器。

## 记录、账号与同步

计时安排可按“文件夹／项目”选择已有项目，也可输入名称创建浏览器项目。同名项目按ID关联，不混合不同文件夹的记录。

“记录”入口按日期查看有效专注历史，也可显示全部日期，逐页浏览。记录包含原始专注／暂停区间、开始与结束时间、项目及结束方式；不足10秒的会话不进入历史。浏览器关闭后已保存历史保留，原版本升级前未保存的历史不能补建。

偏好设置中的“账号与同步”提供邮箱验证码注册登录、邮箱密码登录、退出、手动同步和状态显示。登录后显示姓名与头像，隐藏登录表单，退出登录单独显示。姓名、头像及密码可在桌面软件的账号设置中修改。新邮箱验证后创建账号；登录时可选择合并访客专注历史与通用偏好。各账号与访客数据分别保存在扩展本地，退出不会删除原账号数据。专注及休息期间不能切换账号。

登录后首次同步，其后每隔七天检查一次云端。本机可同步的变更合并约两分钟后自动发送；“立即同步”不受周期限制。同一批失败的变更保留在本机，等下次手动同步、新变更或每周检查再试。同步范围为专注记录、项目、网站黑白名单和通用计时偏好。两端都修改过的项目和设置会显示冲突选择。云端更新不改变本次专注开始时的规则快照。账号功能需要先完成[CloudBase配置与部署](cloudbase-setup.md)。

## 数据与权限

列表、偏好、当前会话、历史与账号资料保存在`chrome.storage.local`，仅扩展可信上下文可访问；面板状态使用`chrome.storage.session`，不包含登录令牌。未登录时不上传数据；卸载扩展会删除其本地数据。

权限用于闹钟唤醒、长期保存专注历史、检查已有标签页和执行网站规则。`unlimitedStorage`用于避免历史及离线同步数据达到扩展本地存储配额后无法保存。账号登录后通过CloudBase HTTP API访问本人数据。扩展不请求`nativeMessaging`，不读取桌面软件数据库，不依赖桌面程序运行。

## 构建与验证

桌面与插件使用同一CloudBase PostgreSQL环境和同步RPC。开发配置从根目录配置示例填写并生成，管理员凭证只保留在服务端。部署步骤见[CloudBase配置](cloudbase-setup.md)。

单独生成扩展，无需 .NET SDK：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/publish-extension.ps1
```

输出为 `artifacts/browser-extension` 和 `artifacts/FocusBloom-browser-extension.zip`。`./scripts/dev.ps1 publish` 同时生成桌面程序和扩展。

计时与规则测试：`node --test extensions/tests/*.test.mjs`。真实浏览器测试设置 `FOCUSBLOOM_PLAYWRIGHT` 为可用 Playwright 模块路径、`FOCUSBLOOM_BROWSER` 为浏览器可执行文件，再运行 `node extensions/tests/integration.cjs`。

9项规则／计时测试通过，覆盖黑白名单、域名匹配、暂停、会话快照、后台恢复、10秒门槛与24小时上限。Edge 与 Chrome 使用独立临时配置实测通过，覆盖无需本地主机运行、已有页面拦截、资源加载、暂停／继续、限制开关、浏览器重开、倒计时／休息、设置保存和专注页全屏。

## 当前边界

扩展通过开发人员模式加载，尚未提交浏览器扩展商店。浏览器内部页面及其他扩展不属于网页限制范围；禁用或卸载插件后，其网站限制停止。

后台闹钟受浏览器调度影响，可能延迟唤醒；计时按真实时间点计算，下次唤醒、打开面板或网页事件时补齐状态并解除到期限制。[Chrome 闹钟接口说明](https://developer.chrome.com/docs/extensions/reference/api/alarms)

扩展不阻止 Windows 应用、其他浏览器，也不执行桌面常亮。桌面软件的常亮电源请求不阻止屏保或系统策略自动锁屏。
