# FocusBloom 浏览器扩展隐私说明

本说明适用于 Chrome Web Store、Microsoft Edge Add-ons 和 Firefox Add-ons 的 FocusBloom 独立扩展。

## 本机保存的数据

扩展在当前浏览器配置中保存专注项目名称、计时记录、偏好和用户主动设置的网站规则。开启网站限制期间，扩展在本机核对标签页网址与规则，按需显示拦截页。拦截页会暂时保留原网址以便在限制解除后恢复访问。扩展不保存浏览历史，也不读取网站页面正文。

商店版不要求登录，数据不会由扩展上传到服务器。扩展不包含广告、分析或遥测。卸载扩展可移除该浏览器配置中的扩展数据。
