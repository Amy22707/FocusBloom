# 数据备份与恢复

日期：2026年10月17日

## 创建备份

进入“偏好设置 → 数据备份与恢复”，点击“创建备份”，选择保存位置。也可以在设置搜索框输入“备份”直接展开该组。

备份保存为单个`.fbbak`文件，包含SQLite数据快照、备份时间与内容清单，以及当前素材清单中的自定义图片、GIF、视频、声音、日期事项封面和组件背景图片。项目、待办、专注记录及成果、日历安排、课表、目标、习惯打卡、心情复盘、句子和设置随数据库一同保存。同名但位于不同文件夹的素材分别打包。

备份使用一致的数据库快照，打包素材在后台进行。界面显示当前处理的素材及进度。原文件已被移走或无法读取时，数据仍保存，完成提示会说明未打包数量；恢复预览中可展开查看具体清单。

## 自动备份

“每天自动备份”默认关闭，开启后每天首次运行时备份一次；软件持续打开时按天检查。可选择保存文件夹，并设置保留最近1至30份，默认7份。

只有`FocusBloom-auto-*.fbbak`自动备份会按保留份数清理。手动备份和`FocusBloom-before-restore-*.fbbak`恢复前备份保留。备份失败时显示原因，一小时后重试；修改保存位置或重新开启自动备份可重新检查。

“打开备份文件夹”可直接找到保存的文件。最近备份时间与路径显示在设置中。

## 恢复与迁移

1. 选择“从备份恢复”，打开`.fbbak`文件。
2. 查看备份时间、各类记录数量、素材数量及未打包文件清单。取消时不修改当前数据。
3. 确认“备份当前数据并恢复”。软件先验证并准备备份，再将当前数据完整保存到备份目录。
4. 软件退出后替换数据库并重新启动，载入恢复的数据。

正在计时、暂停、休息或有未保存记录时，恢复入口仅提示先结束或保存。检测到其他正在运行的FocusBloom实例时，提示先从托盘退出其他实例。恢复采用替换方式，保留备份中的记录ID和关联，不与当前数据合并。

换电脑时，复制备份文件到另一台已安装FocusBloom的电脑，再按相同步骤恢复。素材保存在本机数据目录下的`restored-media`，文件引用和本地素材ID随路径一起调整，保留显示名称、收藏、排序和随机排除设置。导入的图片文件夹也指向恢复后的素材目录。

恢复时保留当前电脑的备份位置、自动开关、保留份数和最近备份信息。恢复前备份可用于回到此前状态。

## 范围

- 备份保存已经落盘的数据，不包含尚未结束或尚未保存的本次专注。
- 浏览器缓存和登录状态不打包。系统安装的字体与受限应用本身不打包，换电脑后可按本机安装情况调整字体和应用路径。
- 无法读取的原素材会保留记录和提示，备份无法补回已经遗失的文件。

## 实现

备份包使用ZIP，包含`manifest.json`、`database.sqlite`与`assets`。SQLite Backup API生成快照，临时文件写完后发布为目标文件；恢复先在工作目录验证数据库并重建素材引用，确认后在旧界面与服务关闭后应用。数据库更新使用SQLite Backup API，未通过准备检查的备份不会替换现有数据。

备份偏好保存在`backup.options`。默认备份目录为`%LOCALAPPDATA%/FocusBloom/guest/backups`。使用备份不需要账号或云服务。
