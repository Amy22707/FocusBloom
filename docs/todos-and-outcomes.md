# 待办与专注成果

日期：2026年10月13日

待办事项使用独立页面，按“文件夹 → 事项”整理，与项目库的文件夹分别管理。专注记录同时保存计时项目及可选待办。两个页面的文件夹栏均可从内容标题旁收起或展开，收起后内容区占用整行。

## 使用

右上角可切换“列表／四象限”。列表显示当前文件夹，一行三张120像素高的卡片；四象限可选择“全部文件夹”或“当前文件夹”，均支持搜索及状态筛选，视图与象限范围在本机保存。“重要”和“紧急”分别勾选，与截止日期及原优先级独立。各象限的“＋”新建时预选对应属性，默认放入左侧选中的文件夹，编辑窗口可选其他文件夹。两个视图共用事项ID、完成状态、排序和计时关联。

四象限采用平面坐标布局：横轴向右表示重要，纵轴向上表示紧急。右上是重要且紧急，左上是紧急不重要，右下是重要不紧急，左下是不重要不紧急。事项为32像素高的小块，完成框保持直接操作，点击名称打开详情，查看完整名称、所属文件夹、截止时间、状态、优先级、投入、备注与下一步，并可编辑或开始专注。事项较多时各象限独立滚动，浅色与深色主题均使用当前配色。

列表卡片的截止日期以较大的半粗体显示；象限小块右侧显示月日及可选时间，未设置日期时留空，悬停可看完整截止日期。逾期事项使用强调色。

1. 在“待办事项”新建文件夹和待办。事项可设置待办／进行中／已完成状态、优先级、截止日期与可选具体时间、预计投入、备注及下一步。按名称或备注搜索，按状态筛选。
2. 文件夹和列表事项支持拖动手柄及排序菜单，顺序在本机保存。编辑事项可移动到其他文件夹，文件夹名称及同一文件夹内的事项名称不可重复；编辑后保持原滚动位置，移动到其他文件夹时显示目标位置。已有事项及历史记录保持原ID。
   四象限事项同样支持无边框手柄拖动及排序菜单，只调整当前显示象限内的顺序，保留重要／紧急属性；当前文件夹、全部文件夹及搜索筛选下均可排序，列表与象限共用保存的顺序。
   已完成事项自动排在未完成事项之后，列表和每个象限均遵循此规则；两组内部保留原有排序。恢复为未完成时回到原排序位置，重开及搜索筛选后仍采用相同规则。
3. 从详情开始专注时可选计时方式、普通／严格模式，以及项目库文件夹和项目。倒计时可设时长；番茄循环可设专注、长短休息、轮数和长休息间隔，专注时长至少10秒；正计时无需设时长。项目留空时使用所选文件夹的“未分类”项目，文件夹也留空则进入全局“未分类”。已用过的项目作为下次初始选择。详情保留5／10分钟快捷入口，进入设置后仍可调整；取消或设置被拒绝时不更改当前计时参数，本次设置不覆盖默认偏好。
4. 在计时准备区先选“待办文件夹”，再从“关联待办事项”选择其中一项；选择“不关联待办”仅按项目计时。切换文件夹后清除上一文件夹的事项，空文件夹仅显示不关联选项；从待办直接进入时自动选中其文件夹与事项，重开恢复上次选择。运行中的会话锁定两级选择，普通、全屏及浮窗显示同一关联。番茄每轮单独保存关联，结束不自动完成待办。
5. 结束或休息时可点击“补记成果”，也可随时在“专注记录”中补填或编辑。文字、数量／单位和下一步均可选；数量填写时须提供单位。成果入口不自动弹出，计时记录立即保存，休息及下一轮照常推进。
6. 最新已保存会话的下一步可作为待办恢复备注，编辑更早的成果不会覆盖较新的恢复备注。非待办专注同样支持成果与下一步，准备该项目时显示最近的下一步。

文件夹和事项均可修改及删除，删除前确认。正在计时、暂停、循环休息或记录未保存的待办及其当前文件夹不可删除，提示先结束并保存。删除保留关联的历史记录与成果，最后一个事项或文件夹可删除。

## 数据与计时

SQLite新增`todo_categories`、`todo_folders`、`todo_items`和`session_outcomes`；`sessions.todo_id`为可空外键，已有记录保持为空。待办与文件夹软删除，保留历史关联；会话ID用于编辑对应成果，后续新会话不会改变已经打开的成果编辑目标。

四象限范围保存在`todos.quadrantScope`，排序保存在`todos.order`，待办页面的文件夹选择保存在`todos.folder`，计时准备区的待办与文件夹选择分别保存在`focus.todo`和`focus.todoFolder`。成果单独保存，不修改自动记录的专注区间、时长或完成状态；不足10秒的会话仍不保存，也不显示本次成果入口。

严格专注记录同时保存本轮拦截次数，包含受限应用提示及学习浏览器主页面／弹窗的拒绝访问，后台嵌入资源不计数。同一应用提示持续显示不重复累计，再次触发计为新一次；暂停继续统计，休息不统计，每轮番茄重置。普通模式显示“—”，此前没有计数数据的严格记录显示“未统计”，记录不足10秒仍不保存。
