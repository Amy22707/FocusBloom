# 开发交接：桌面计时浮窗与专注功能

日期：2026年10月12日

## 角色与任务

开发窗口：实现桌面计时浮窗，共用当前计时并提供纯色／当前背景选择。

## 完成内容

- Windows截图工具、截图浮层及“照片”查看器在应用黑名单／白名单模式中均默认放行，覆盖SnippingTool、ScreenClippingHost、Photos和Microsoft.Photos，设置页同步显示说明。

- 当前计时浮窗从主窗口顶部、偏好设置或托盘开关，显示项目、时间、状态与轮数，共用开始／暂停／继续／结束／跳过休息命令。主窗口进入托盘后继续显示，收起浮窗不停止计时，明确退出软件时关闭浮窗。
- 浮窗支持拖动、缩放和独立置顶，最小240×180，记住位置、尺寸、显示器、显示状态、背景样式及透明度；显示器变化后返回可见范围。同屏全屏时暂时隐藏，退出全屏或隐藏主窗口后恢复。
- 右上角仅保留无底色的设置与收起图标，菜单提供置顶、背景和透明度滑块。透明度范围0%至70%，使用WPF透明窗口与整体不透明度，设置菜单保持清晰；图片背景无浅色外边框，仅保留圆角。
- 浮窗可选纯色或本轮计时背景，复用静态／GIF／视频控件，隐藏或切为纯色时释放动态播放资源。主题和数字字体跟随主界面，切换背景不刷新本次图文。
- 透明浮窗的视频验证覆盖默认1080p视频解码与实际渲染画面，预览为`timer-float-video.png`。

- 桌面计时方式新增番茄循环，可配置专注、短休息、长休息、长休息间隔和总轮数，并保存为默认偏好。默认25／5／15分钟、每4轮长休息、总4轮；每轮单独记录，最后一轮停止，休息可跳过，循环可随时结束。
- 倒计时及番茄专注时长不足10秒时弹出主题提示，拒绝开始或保存循环偏好；恰好10秒允许，长短休息可为0。提前手动结束的不足10秒会话继续排除记录。
- 严格专注及暂停保持限制，休息解除；下一轮重新复制规则并选取图文。循环休息中仍保护当前项目，需结束循环后删除。睡眠后按应结束时间保存当前轮，最多从当前时间启动一个下一轮。

- 背景支持静态图片、GIF及MP4／WMV视频。普通与全屏页循环播放，计时暂停继续播放；离开页面或隐藏到托盘时释放资源，返回后重播同一素材。背景视频始终静音，声音面板独立控制环境声。
- 视频素材卡片后台取一帧作为静态缩略图，复用加载任务和冻结图片缓存，保留小型播放标记；加载或不可用时显示对应提示。
- 桌面有效专注不足10秒的会话结束后提示未计入，不保存记录、不计入统计，暂停时间不计入有效时长；满10秒正常保存。退出时同样排除短会话，不弹窗。
- 文件夹、项目、图片、文字和声音均可排序：无边框淡色“≡”手柄拖起卡片预览，跟随鼠标并平滑让位，松开才保存，取消恢复，支持边缘滚动；点击手柄可前移、后移或移到首尾。顺序本机保存，当前选择与专注保持，默认和自定义素材均支持，收藏筛选中也可排序。
- 自定义背景支持修改软件内的显示名称，原文件名、文件路径、缩略图、收藏、排序与当前播放保持；默认背景不可改名。
- 默认背景包含6张Pexels图片及1080p、约29.97帧/秒的“林溪流光”视频，视频来源为BLM Oregon & Washington，采用CC BY 2.0。发布片段保留清晰画面、去掉原音频，作者、来源与许可随包保留。
- 默认句子采用用户确认的25条正文与出处，英文“After all, tomorrow is another day.”署名Margaret Mitchell，作品Gone with the Wind；原月亮句保存为本机自定义摘录。风暴句作品名按用户要求采用《颂歌集》。五项尚无可核对原作依据的归属按用户决定沿用，核对记录见 `docs/quote-sources.md`。
- 默认图片、文字和声音不可删除，默认文字不可编辑。图片和文字可设置“不参与随机”，仍能手动固定选择；无随机候选时使用主题背景或不显示句子，计时照常。
- 自定义句子可编辑正文和全部出处字段，保存或取消后回到原卡片位置；英文作品名使用斜体。编辑当前句子不改变正在进行的专注，下次采用新内容。
- 自定义素材、文件夹、项目、应用规则及网站规则删除前均需确认；素材删除保留本地原文件，项目删除保留历史记录。浏览器独立插件的网站删除同样提供确认。
- 严格限制开始时记录已有窗口。拦截提示显示期间保留目标窗口；点击“返回专注”后，已有可见窗口最小化、隐藏窗口恢复隐藏，新打开窗口收到正常关闭请求，由该软件决定退出或回到托盘。后台进程不强制终止。
- 全屏专注页顶部依次显示“学习浏览器”和“返回窗口”，返回窗口位于最右侧。
- 普通与全屏页的声音弹窗使用连续像素滚动，音源行紧凑排列，末项可完整显示且底部无额外空行。
- 已有素材偏好加载时不会重复显示提升为默认的句子，旧默认编辑及删除记录不覆盖当前默认库；收藏、随机排除和自定义素材继续本机保存。
- 文件夹名称不可重复，同一文件夹内的项目名称不可重复，新建、改名和移动均校验首尾空格与英文大小写。不同文件夹允许同名项目。
- 文件夹的最后一个项目可删除，空文件夹继续保留；正在计时、暂停或记录未保存时点击删除，仅显示说明和“知道了”，先结束并保存后才能进入删除确认。
- 专注期间锁定的本次计时设置及应用／网站规则显示“请先结束专注”的说明，结束后恢复编辑并收起说明。
- “这次，专注什么？”将上一次文件夹和项目选择保存在本机，重开恢复；按项目 ID 跟随改名及移动，删除后回退到可用项，空文件夹选择也可保留。尚无选择偏好时优先采用最近的可用专注记录项目。
