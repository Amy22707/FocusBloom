## 完成内容

桌面左下角显示账号姓名和头像，收起导航仍保留入口，点击进入资料编辑。账号设置区分已登录与访客状态，登录后隐藏邮箱验证码表单，单独显示退出登录。姓名与头像保存在CloudBase身份认证中，本机缓存用于离线显示。

桌面提供邮箱二次验证设置或修改密码，登录页可切换验证码与密码登录。密码只在本次HTTP请求中使用，成功后清空，不写入数据库或同步资料。

桌面开发版通过CloudBase PostgreSQL RPC同步项目、有效专注记录、网站名单及通用计时偏好。同步表禁止客户端直接访问；函数按账号分配版本、事务提交、记录去重及分页返回依赖项目。心情、照片、待办正文与本机路径继续只保存在本机。

桌面访客合并包含全部已保存本地内容、关联、分组与偏好。已登录账号提供“导入本机原有数据”，导入前自动备份，保留账号已有条目、当前账号资料与同步状态，在旧窗口保存完布局后应用。

已提供[品牌邮件说明](branded-email.md)和[验证码邮件模板](../cloud/email/verification.html)。自定义发件邮箱需要在CloudBase控制台配置SMTP。

## 部署与后续

姓名、头像和密码使用现有身份认证接口，不需要修改同步表或重复执行SQL。邮箱密码登录需在CloudBase身份认证中开启“用户名密码登录”，配置步骤见[CloudBase教程](cloudbase-setup.md)。真实账号的头像上传、设密及双向同步需在软件中操作确认。

发布后保留原安装目录和数据目录，扩展在原目录更新后重新加载。程序运行时需要先从托盘退出再覆盖文件。源码与发布记录以 GitHub 主分支及 Releases 为准。

本机桌面程序、随包扩展、独立扩展和ZIP已更新，扩展版本0.3.4；访客与账号数据库快照保留。软件保持关闭，重新打开后使用新版，浏览器扩展需重新加载。

公开认证与令牌刷新请求不附带Authorization，受保护资料和同步接口继续传入用户令牌。过期会话保存资料的回归检查通过，真实会话刷新、资料读取和不含修改字段的资料请求均成功。15项桌面账号专项与8项扩展同步专项检查通过。
