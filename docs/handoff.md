# 开发交接：桌面专注界面

日期：2026年10月10日

## 角色与任务

开发窗口：完善专注界面与素材管理，提供背景、文字、声音卡片选择及收藏／删除。

## 完成内容

- 普通与全屏专注页展示项目、计时、状态、图片与句子；沿用6种既定配色及浅／深／系统主题，背景填充适配并叠加暗色遮罩。
- 专注字体提供中文、英文、计时数字的候选卡片及组合预览，数字候选包含工业机械、机械刻字、窄体仪表、终端等宽及打字机等风格，只展示本机可用字体。修改即时同步普通／全屏专注页及文字卡片，本机保存并支持恢复默认；切换不更换当前图文和计时状态。
- 句子适度放大，主要计时操作居中；底部左右分别提供按钮式常亮开关和声音面板，尺寸接近主要操作并略小一档，图片来源与顶部学习浏览器采用低调入口，图文管理位于偏好设置。
- 学习浏览器采用顶部标签页与紧凑地址栏，主色突出“返回全屏／返回计时”，“打开”为地址栏内的小按钮；全屏切换为图标，沿用现有配色与会话。
- 偏好设置的背景、文字、声音区域默认折叠，点击标题展开素材卡片，直接使用、收藏、删除和筛选收藏；背景与文字可只从收藏随机，默认素材可恢复。删除状态本机保存，不删除用户文件，不改变本次图文快照；删除正在使用的音源停止播放。
- 应用阻止界面先激活专注窗口再隐藏，前台事件读取当前实际前台窗口；单次返回后保持严格规则，再次切换受限应用继续拦截。
- 每次成功开始新专注时分别选择背景与文字。同一会话在暂停／继续、全屏、主题切换、学习浏览器和托盘恢复时固定；多个随机候选时避免连续重复。
- 背景支持随机、固定、纯色主题、本地图片及文件夹，提供收藏／排除与仅从收藏中随机。文件夹在启动与新专注时读取，没有可用图片时继续使用主题背景。
- 默认采用文档指定的25句文字，支持自定义句子添加／编辑／删除、TXT每行一句导入及作者、作品、译者与来源。图文偏好本机保存，专注中修改在下一次采用。
- 首批默认6张 Pexels 图片、CC0轻雨与壁炉录音、白／粉红／棕合成噪音离线随包提供；界面显示来源并提供原始页面入口。
- 普通页、全屏音量面板及设置页共用音源、播放／暂停、音量和静音。支持本地音频，循环末尾与开头交叉淡化，计时暂停不改变播放；退出释放播放器。
- 专注与休息结束提供可关闭的原创提示音，遵循音量和静音偏好。
- Windows x64发布目录已覆盖，包含默认图文与音源、NAudio依赖；使用说明见 `docs/focus-interface.md`。

现有桌面功能保留文件夹项目、正／倒计时与默认偏好、暂停／休息、SQLite记录、应用与内置浏览器黑白名单、托盘、窗口布局恢复、常亮和独立全屏学习浏览器。Edge／Chrome插件保持独立运行。
