# 开发交接：专注中断恢复与浏览器插件界面

日期：2026年10月21日

## 完成内容

- 桌面计时每5秒及状态变化时自动保存。重开后可继续专注、恢复暂停／休息、保存并结束，或确认放弃。保留项目、待办、原始区间、番茄轮次、拦截次数与本次严格规则；中断期间不计入有效时长，不补跑关闭期间错过的轮次。
- 已有正式记录的会话不重复恢复；不足10秒的部分沿用原有规则。保存失败保留恢复入口，可重试；自动保存失败显示错误。待处理期间不能开始另一段专注或删除关联项目、待办。
- 恢复窗口可暂时关闭，从主窗口顶部再次打开；正常结束或明确退出清除自动保存，关闭到托盘继续计时。
- 浏览器扩展0.2.2采用“专注时刻／网站规则／偏好设置”导航，面板突出大号计时与主操作，设置独立展示。专注页使用侧栏和内容标题，窄窗口切换为顶部导航；配色、明暗与圆角风格沿用桌面版。
- 正计时在桌面及插件均于累计有效专注24小时后自动结束，不进入休息，解除限制与常亮；用户再次打开时显示一次提示。桌面自动保存正式记录，插件保留当前会话。两端倒计时10秒至24小时；扩展提前结束不足10秒标记未计入，暂停与休息不计入有效时长。

## 实现与数据

`FocusCheckpoint`由`FocusTimer`捕获及恢复，`MainViewModel.Recovery.cs`保存到现有SQLite设置`focus.checkpoint`，没有新增数据库表。结束原因增加`Interrupted`，用于保存中断前的有效记录。正式记录的会话ID去重逻辑保持。

插件沿用原独立计时和黑白名单逻辑，`popup.html`、`page.css`、`page.js`管理新导航与布局，`theme.mjs`与桌面主题使用相同配色及混色比例。

详情见[专注中断恢复](focus-recovery.md)和[独立浏览器扩展](browser-extension.md)。
