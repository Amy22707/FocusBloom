# 开发交接：数据备份、恢复与迁移

日期：2026年10月17日

## 完成内容

- “偏好设置 → 数据备份与恢复”提供创建备份、恢复预览、打开备份文件夹，以及自动备份设置；可通过设置搜索定位，分组展开状态保存。
- 单个 `.fbbak` 文件包含一致的SQLite快照、内容清单和自定义素材，覆盖项目、待办、专注记录与成果、日历课表、目标习惯、心情复盘、句子、设置，以及图片、GIF、视频、声音、封面和组件背景。
- 素材按原文件夹分别打包，同名文件不冲突。已无法读取的素材列入清单；工作文件写完后发布备份，失败和取消不留下目标备份。
- 恢复前展示时间、各类数量和素材清单，确认后验证、准备数据并创建恢复前备份。计时、暂停、休息、记录未保存时仅提示先结束或保存；检测到其他FocusBloom实例时提示退出其他实例。
- 旧窗口及服务关闭后应用恢复，重新启动软件。采用替换方式，保留记录ID及关联；素材转入本机 `restored-media`，同步修改路径与本地素材ID，保留显示名、收藏、排序和随机排除设置。
- 自动备份默认关闭，开启后每天一次；保存位置可选，保留最近1至30份，默认7份。仅清理超额自动备份，手动和恢复前备份保留；本机备份偏好在恢复时保留。
- 备份前保存当前素材清单，启动时从导入文件夹新发现的图片也随备份保存。

## 实现

`FocusBloom.Infrastructure/Backup`包含归档、检查、准备与应用恢复、日期及保留规则。`BackupSettingsViewModel`处理偏好、进度和自动调度；`BackupSettingsView`与`BackupRestoreWindow`提供设置与确认。`MainWindow`接入设置搜索和恢复请求；`App`在退出时完成备份任务收尾、释放旧界面服务后应用恢复并重启。

配置保存在 `backup.options`，默认目录为 `%LOCALAPPDATA%/FocusBloom/guest/backups`。不依赖账号或云服务。浏览器登录状态及系统安装的字体、应用不打包；尚未保存的本次专注不纳入备份。

使用说明见 [数据备份与恢复](backup-and-restore.md)。README已同步。
