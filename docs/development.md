# FocusBloom 开发与项目说明

Windows 专注与学习管理软件。围绕项目分类计时，连接学习计划、实际记录和每日复盘。

当前提供文件夹与专注项目、正计时／倒计时、普通／严格模式、应用及网站黑白名单、内置学习浏览器、Edge／Chrome 独立扩展、常亮、定时暂停与继续、手动／到点结束、可选休息、SQLite 自动记录、可选配色与明暗模式、托盘、窗口置顶与全屏计时。

“心情与复盘”提供独立月历与心情趋势，支持过去日期补记、标签、简短复盘与每日提醒，并自动汇总当天专注、待办完成和习惯打卡。使用说明见[心情与每日复盘](mood-and-daily-review.md)。

“偏好设置 → 桌面浮窗与组件”可开启专注时长、待办、日期事项、习惯、心情月历和日历与课表组件，独立选择视图、范围、颜色、图片背景、尺寸、透明度与置顶；主窗口进入托盘后继续显示。使用说明见[桌面组件](desktop-widgets.md)。

“偏好设置 → 数据备份与恢复”提供完整备份、恢复预览和换电脑迁移，自定义图片、视频、声音与封面随备份打包。可开启每天一次的自动备份，自选位置并保留最近1至30份。使用说明见[数据备份与恢复](backup-and-restore.md)。

工作区采用紧凑导航和内容工具栏，待办突出名称与截止日期，月历展示多条事项，周视图与课表保留日期表头。界面说明与预览范围见[工作界面](workspace-ui.md)。

程序、窗口、托盘及主界面采用统一品牌图标。启动时显示图标、“一刻专注”和“把时间留给喜欢的事。”，本地数据初始化完成后进入主界面。品牌图标由本地提供，不随仓库分发；构建前需将 `FocusBloom.png` 与 `FocusBloom.ico` 放入 `src/FocusBloom.Desktop/Resources/Branding/`。

## 开发环境

Windows x64，.NET 10 SDK。界面采用 WPF，本地存储使用 Microsoft.Data.Sqlite，浏览器使用 WebView2，测试使用 xUnit。依赖由 NuGet 自动还原。学习浏览器需要 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)，普通计时可独立使用。

可以使用系统安装的 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)，也可以在项目根目录安装本地 SDK：

```powershell
./scripts/bootstrap.ps1
```

本地 SDK 位于 `.tools/dotnet`。开发脚本优先使用这一份，否则使用系统 `dotnet`；SDK 和 NuGet 缓存不进入仓库。

## 构建与运行

在项目根目录执行：

```powershell
./scripts/dev.ps1 build
./scripts/dev.ps1 test
./scripts/dev.ps1 run
```

构建与测试默认使用 Debug；发布构建可执行 `./scripts/dev.ps1 build -Configuration Release`。

项目库按文件夹组织项目：点击“新建文件夹”打开名称弹窗，再通过列表标题旁的“新建项目”添加英语阅读、数学等项目，并选择所在文件夹。列表不常驻输入框。专注页先选文件夹与项目，再选择计时方式、暂停及休息设置后开始。原有项目的分类会显示为相应文件夹。

“待办事项”按文件夹与事项整理，列表一行三张紧凑卡片，四象限可选择当前文件夹或全部文件夹，点击事项查看详情。支持状态、优先级、截止日期／时间、预计投入、备注、搜索筛选、排序、编辑和删除；项目库及待办文件夹栏均可收起。待办启动弹窗可设置计时方式、普通／严格模式及倒计时或番茄参数，并选择计时文件夹及项目，留空使用“未分类”。每轮记录保留待办关联，结束不自动完成。成果、数量／单位和下一步可在结束后或记录页补填，不阻断休息或下一轮；未关联待办的专注同样支持。详见[待办与专注成果](todos-and-outcomes.md)。

“日历与课表”的日／周／月／年展示待办截止和日期事项，课程仅在周课程表展示；支持多个上课时段、24种颜色、自定义颜色和临时调课。“专注记录”提供可读的记录时间轴及日／周／月／年视图，展示有效时长、待办、成果与严格拦截次数。日视图可选单双列，日期可用年份／月份列表跳转。“日期事项”管理正数／倒数、封面、置顶、循环和提醒。设置提供提醒总开关及各板块事项块缩放，Windows／Outlook同步入口待接入。详见[日历与提醒](calendar-and-reminders.md)。

“专注记录”内提供统计和复盘：日期／项目／待办筛选、时长与次数指标、柱状图、项目占比和年度热力图，图表可点击查看明细。复盘展示待办当前状态、预估与累计投入、成果及下一步，支持Markdown摘要和CSV明细导出。详见[统计与复盘](statistics-and-review.md)。

偏好设置提供导航栏目显示与拖动排序、功能分组折叠和关键词搜索；显示顺序与展开状态保存在本机。热力图及柱状图悬停显示秒级总时长。详见[导航与设置](navigation-and-settings.md)。

“目标与习惯”支持时长／次数／打卡天数目标，按日／周／月／累计周期计算，习惯支持执行频率、当天打卡、连续完成和历史月历。目标进度连接统计与摘要，习惯提醒受软件总开关控制。详见[目标与习惯](goals-and-habits.md)。界面测试使用[独立测试桌面](isolated-testing.md)。

正计时可随时结束，累计有效专注达到24小时后自动结束并保存；倒计时为10秒至24小时，到点结束。暂停与休息不计入有效专注时长。分钟数支持小数。达到正计时上限后不进入休息，解除限制与常亮，用户再次打开软件时提示一次。

设置页的“计时偏好”可保存默认计时方式（正计时／倒计时／番茄循环）、默认专注模式（普通／严格），以及暂停和休息时长。保存后每次准备开始采用默认选择，软件重开后恢复；专注页临时调整只作用于本次会话。计时期间保存新偏好在下一次专注生效，当前计时及限制状态保持原设置。

番茄循环可设置专注、短休息、长休息、长休息间隔与总轮数，默认25／5／15分钟、每4轮长休息、共4轮。每轮专注单独保存记录，休息自动进入下一轮；可暂停、继续、跳过休息或随时结束，最后一轮结束后停止。严格暂停保持限制，休息解除限制，下一轮重新应用。睡眠后按原定终点保存当前轮，最多启动一个新轮次，从唤醒时开始计时。

倒计时与番茄循环的专注时长至少10秒，输入不足10秒时弹出提示，拒绝开始计时或保存循环偏好；休息仍可设为0。提前结束导致有效专注不足10秒时，仍按短专注规则提示并不保存记录。

项目库中的文件夹与项目通过“···”修改或删除，项目还可移动到其他文件夹。文件夹不可重名，同一文件夹内的项目不可重名，跨文件夹可同名。删除需确认，最后一个项目也可删除并保留空文件夹；文件夹删除会同时移除其中项目，历史专注记录与时长保留。正在专注或记录未保存时仅提示先结束并保存，提示窗口不提供删除按钮。详情见 [文件夹与项目管理](project-library.md)。

文件夹、项目、背景、文字和声音均可通过淡色“≡”手柄拖动排序，也可点击选择前移、后移或移到首尾。顺序本机保存，计时选择与素材列表同步，排序保持当前会话。

拖动时显示跟随鼠标的卡片预览，其他项目平滑让位，松开后保存顺序，取消则恢复原位。自定义背景可修改软件内显示名称，原文件名保持不变；默认背景不可改名。

严格模式先在设置中选择应用和网站各自的规则：白名单仅允许列表内，黑名单仅限制列表内。黑白列表独立保存，原有列表保留为白名单。应用可选择运行中的程序或 `.exe` 文件；网站填写域名或网址，选择是否包含子域名。每次严格专注采用开始时的模式与列表，暂停维持限制，休息／结束／退出解除限制。

切到受限应用时，显示覆盖屏幕的阻止界面并将焦点交给它，保留受限窗口的状态及进程后台运行；可返回专注或随时结束。软件自身、必要系统界面、任务管理器、Windows 截图工具及“照片”查看器自动放行，黑名单和白名单均适用，方便截图后查看与保存。外部浏览器按所选应用规则处理。解除后应用恢复正常操作。

从计时页或计时全屏点击“学习浏览器”进入浏览器；点击“返回计时”回到当前计时。浏览器支持独立全屏、地址栏、前进／后退、刷新、标签页、弹窗和允许网站入口，全屏切换保留同一网页及标签页。严格模式检查已有页面、页面跳转、重定向及新窗口；受限页面显示阻止界面，站点所需图片、脚本和接口保持加载。

Edge／Chrome 独立扩展提供自己的正／倒计时、暂停／休息、网站黑白名单及6种配色，无需桌面软件、本地通信主机或注册脚本。面板与可全屏专注页共用同一会话，浏览器重开后恢复计时。桌面与扩展分别保存规则、分别计时；桌面严格模式中，外部浏览器仍按应用规则放行。安装步骤见 [独立浏览器扩展](browser-extension.md)。

计时页与全屏计时页可开启“保持屏幕常亮”，专注及暂停期间防止空闲关屏／睡眠，休息、结束及退出释放请求，开关偏好在本机保存。

主窗口顶部、偏好设置及托盘可开关“计时浮窗”。浮窗显示同一项目、时间与状态，可开始、暂停、继续、结束、跳过休息及返回主窗口。主窗口进入托盘后继续更新，关闭浮窗只收起卡片；明确退出软件时全部关闭。支持拖动、缩放和独立置顶，最小240×180，重开恢复布局与显示状态。右上角只显示设置和收起图标；设置菜单可选择置顶、纯色或当前计时背景，并以滑块调节0%至70%的透明度，选择在本机保存。当前背景跟随本轮图片、GIF或视频，采用无边框圆角；配色、明暗与计时字体同步主界面，切换背景不改变本次专注。同屏进入全屏时暂时隐藏浮窗，退出全屏或隐藏主窗口后恢复。

背景支持本地 GIF 动图及 MP4／WMV 视频，使用“添加背景”或“添加文件夹”导入，与静态图片共用收藏和随机选择。普通／全屏专注页循环播放，卡片显示“GIF 动态”或“视频循环”；背景视频默认静音，切换页面或隐藏到托盘时释放播放资源，返回后播放同一素材。

视频背景卡片在后台取一帧作为静态预览，缓存加载结果。有效专注不足10秒的会话结束后提示未计入，不保存记录或计入时长；满10秒正常记录，暂停时间不算有效时长。

专注页与全屏页提供背景图、励志句与声音控制。每次新专注随机选取图文，同一次专注在暂停／继续、主题切换、全屏、学习浏览器及托盘恢复时保持固定。可选择固定图文或纯色主题背景；偏好设置中的“专注图文与声音”按需展开背景／文字／声音卡片，直接选择、收藏、排除随机和恢复默认素材，支持本地图片与文件夹，以及带作者、作品、译者和来源的个人摘录。卡片标记“默认／自定义”，默认图片、文字和声音不可删除，默认文字不可编辑；自定义句子支持编辑，保存后回到原卡片位置，自定义素材删除需确认。英文作品名以斜体展示。默认库包含6张 Pexels 静态背景、1段 CC BY 2.0 的1080p瀑布视频、用户确认的25句文字及5种离线声音，素材来源在界面保留，句子资料见 [默认句子出处](quote-sources.md)。

声音支持播放／暂停、音量、静音及本地音频，循环时交叉淡化衔接；计时暂停不自动暂停声音。专注与休息结束提供可关闭的提示音，静音时不播放提示。使用说明见 [专注图文与声音](focus-interface.md)。

偏好设置提供莫兰迪雾蓝、鼠尾草绿，以及马卡龙奶油杏、樱花粉、薄荷绿、淡紫共 6 种配色；明暗可选浅色、深色或跟随系统。初始使用雾蓝并跟随系统。专注字体另提供中文、英文与计时数字的示例卡片选择和组合预览，可恢复默认。切换即时生效，外观偏好在本机保存。

关闭窗口进入托盘。托盘可打开、暂停／继续、结束和退出。设置页也提供退出入口；明确退出会结束并保存当前专注。

软件全屏根据计时状态展示：专注及暂停进入专用计时全屏，休息或未计时显示完整软件全屏。专注结束或进入休息时，计时全屏切回完整软件全屏。学习浏览器提供自己的全屏按钮；从计时全屏进入浏览器后可直接使用浏览器全屏，并随时返回计时。退出全屏恢复原窗口的位置、尺寸和置顶状态，切换展示方式保持同一次专注及网页。

首次打开按屏幕工作区确定窗口大小，保留标题栏和边缘的操作空间。关闭到托盘或退出软件时保存窗口的位置、尺寸、最大化状态及置顶偏好，软件重启后恢复；屏幕空间不足时调整回可见区域。全屏期间保存全屏前的普通窗口布局。

本机数据保存到 `%LOCALAPPDATA%/FocusBloom/guest/focusbloom.db`，重新启动后保留文件夹、项目、已结束记录、上次选择的文件夹与项目、计时及外观偏好。删除该文件会删除相应个人数据。

生成包含运行时的 Windows x64 文件夹：

```powershell
./scripts/dev.ps1 publish
```

输出为 `artifacts/windows-x64/FocusBloom.exe`。此命令提供可运行文件夹，安装包在发布阶段制作。

独立扩展发布到 `artifacts/browser-extension/`，压缩包为 `artifacts/FocusBloom-browser-extension.zip`；桌面发布目录也包含 `extension/`。扩展通过开发人员模式直接加载。

单独生成插件，无需 .NET SDK：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File ./scripts/publish-extension.ps1
```

## VS Code

使用 VS Code 打开项目根目录，安装微软 [C# 扩展](https://marketplace.visualstudio.com/items?itemName=ms-dotnettools.csharp)。仓库包含扩展推荐、构建／测试／运行／发布任务和调试配置。按 Ctrl+Shift+B 构建，通过“运行任务”选择其他操作。

F5 调试时按 SDK 安装位置选择“FocusBloom（本地 SDK）”或“FocusBloom（系统 SDK）”。XAML 使用文本编辑，运行程序查看效果。Avalonia 不属于本工程依赖。

## 当前边界

账号同步及后续学习管理模块按方案交付。默认素材库可继续扩充，在线背景库后续接入。应用限制需继续在常用软件、提升权限窗口、独占全屏和多屏环境实测。

常亮电源请求不阻止屏保或系统策略自动锁屏。扩展目前通过开发人员模式加载，尚未提交浏览器扩展商店。

运行中的会话定期保存中断恢复状态，结束时写入正式记录；重开后可继续或保存已确认的部分，关闭期间不计入专注。详见[专注中断恢复](focus-recovery.md)。托盘和全屏功能的真实桌面交互需按交接场景验证。

开发环境遇到 WPF 中间资源缺失时，可执行 `dotnet build FocusBloom.sln -c Release -t:Rebuild` 重新生成。

源码已公开，正式许可尚未确定；品牌、美术和第三方素材分别处理授权。
