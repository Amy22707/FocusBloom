# FocusBloom 工作区同步与单机验收报告

## 已交付

| 功能 | 使用方式 |
| --- | --- |
| 桌面工作区同步 | 更新云端 SQL 后，在「偏好设置 → 账号与同步」使用。同步待办、分组、专注成果、恢复备注和待办关联，以及项目计划、日历安排、日期事项、课表、习惯打卡、目标和文字复盘。 |
| 项目计划 | 在「项目库」新建或编辑项目，填写目标、项目截止日期，添加和勾选里程碑。项目卡片显示日期及完成进度。 |
| 课表批量导入 | 在「课程管理 → 导入 CSV」选文件；导入前校验所有行，提示新增数量，确认后一次保存。已存在的等价时段跳过。 |
| 找回密码 | 在桌面账号页选择「密码登录 → 忘记密码？」，获取账号邮箱验证码、输入两次新密码并重置，然后用新密码登录。 |
| 单机验收 | 用 `--data-dir` 指定独立的资料目录。账号切换和重启继续使用原参数，内置浏览器缓存独立，系统提醒关闭。 |

同步按对象记录版本，同一对象的离线冲突可选本机或云端，删除同步到另一端。照片和封面路径保留在本机，基础接口对旧桌面与扩展保持原有范围。

## 已验证

本机命令行共通过 **21 项 .NET 检查、5 项 PostgreSQL 检查和 8 项扩展同步检查**。其中一项端到端检查在同一台电脑上用 A、B 两个独立 SQLite 数据库连接本地 PostgreSQL，覆盖上传下载、多页同步、离线修改与冲突选择、删除传播、账号隔离、保留照片路径，以及专注记录与待办、成果的关联。另有旧 SQL 约束升级保留已有数据、旧接口不返回工作区资料、验证码重置请求及 CSV 校验的检查。

没有打开应用或浏览器界面、连接真实账号、修改云端配置或覆盖日常版本。真实邮件、账号操作和生产云端的往返同步待下列验收。

## 使用预览包验收

1. 构建包位于工作区的 `artifacts/workspace-preview/windows-x64`。如需连云，把已配置版本旁边的 `cloud-config.json` 复制到预览程序旁；也可使用该目录的 `cloud-config.example.json` 填写后另存为 `cloud-config.json`。不需要在聊天里提供配置或密码。
2. 在 CloudBase 的 PostgreSQL SQL 编辑器，选择正确的环境，执行预览包旁的 `focusbloom-postgresql.sql`。脚本保留现有记录，可重复执行。未更新 SQL 时，桌面仍同步基础数据，并提示工作区同步未部署。
3. 建议使用**专门的测试邮箱**和以下两个新目录。每次运行一套，完成一边后从托盘退出，再启动另一边；两边均用同一测试账号，使用普通模式。

   ```powershell
   & '.\artifacts\workspace-preview\windows-x64\FocusBloom.exe' --data-dir "$env:TEMP\FocusBloom-验收-A"
   & '.\artifacts\workspace-preview\windows-x64\FocusBloom.exe' --data-dir "$env:TEMP\FocusBloom-验收-B"
   ```

4. 在 A 新建一条待办及一条关联专注成果，点击「立即同步」。在 B 登录同一测试账号并同步，确认待办、成果和关联均可见。在 B 修改恢复备注并同步，再回 A 核对。在一端退出网络后编辑，联网同步，再到另一端确认。测试删除只删除测试事项。
5. 真实身份认证可用该测试账号试一次头像上传、设置密码和找回密码。密码登录需在 CloudBase 启用相应登录方式；品牌验证码邮件按[配置说明](branded-email.md)配置自有发件邮箱。另测扩展时，可用独立浏览器资料夹加载扩展，登录同一测试账号，验证基础记录和规则往返。

课表 CSV 示例（UTF-8，星期为 1 至 7，节次与周次遵循当前学期；周次留空表示整个学期）：

```csv
课程,星期,开始节,结束节,周次,教室,教师
统计学,1,1,2,"1,3-5",理教101,王老师
统计学,3,3,4,1-8,理教102,王老师
```
