# 工作界面

日期：2026年10月21日

## 内容与工具

顶部品牌栏高度52，保留品牌、计时浮窗、置顶及内容全屏入口。导航展开宽160、收起宽64；页面内文件夹继续单独收起，原有展示顺序和折叠偏好保留。状态栏高度24。

界面使用原有马卡龙／莫兰迪配色，明暗主题使用动态资源。标题、辅助文字和操作按钮区分层级，边框保持轻量，常规控件缩小内边距，选择框内部随Padding布局，紧凑控件也能完整显示文字。

## 页面

- 待办以文件夹名称为当前标题，搜索、视图和新建集中在同一内容区。卡片固定基准高度104，可继续通过原有滑块缩放；突出名称及截止日期，当前年份简写为月日，跨年显示年份，完整日期保留在提示中。卡片空白区域和标题均可打开详情，编辑及拖动操作在鼠标移入或键盘焦点进入后显示，完成事项继续置于最后。
- 四象限保留重要向右、紧急向上的坐标轴。各象限使用紧凑行，保留截止日期、完成和拖动入口，可分别添加事项。
- 日历将年份、月份和日期跳转放入日期标题的弹出面板，课程管理、提醒及ICS导出置于更多菜单。月历按实际空间显示多条事项，剩余数量入口进入当天；周视图和课表表头在滚动时保留。课程仍只在课程表展示。
- 项目库以当前文件夹为主标题，缩小文件夹区，保留项目统一尺寸与新建弹窗。
- 专注页将可选待办关联收起，计时说明以提示展示，主要计时设置保留更多空间。
- 统计范围筛选默认折叠，标题说明当前范围，展开状态保留。图表、模块选择、顺序及明细入口沿用原有行为。
- 目标与习惯卡片减少常驻辅助信息，提醒仅在开启时展示；习惯、日期事项提供简短空状态与直接添加入口。心情、日期事项及设置沿用统一的间距、控件与主题。

## 分组与显示范围

日期事项支持新建、改名和删除分组；新建或编辑事项时选择所属分组。原有事项归入“未分组”。默认分组保留，删除自定义分组前确认，组内事项移回“未分组”，日期、正倒数模式、重复、提醒和关联内容保留。

显示范围可选择“全部分组”或具体分组。单组使用卡片网格；存在多个分组时，全部分组按列展示，每列保留名称、数量和添加入口。各列独立向下滚动，列多时横向滚动；编辑返回后保留浏览位置。分组及选择范围保存到本地。分组标题中的拖动手柄可调整左右顺序，默认分组也可排序，顺序同时用于范围选择及事项编辑窗口。勾选“混合查看”后，事项按置顶和日期显示在同一个网格；右侧分组按钮可勾选参与显示的分组，卡片标明归属。混合模式和勾选范围保存，下次打开恢复。

待办的列表及四象限分别记忆“当前文件夹／全部文件夹”。列表的全部文件夹视图按列展示，每列可添加、管理文件夹；完成项置于列底部，可折叠，折叠状态保留。搜索及状态筛选作用于所选范围。项目库同样提供当前／全部文件夹切换，项目卡片显示所属文件夹；从全部项目选择后，计时配置仍关联正确的文件夹和项目。

## 拖动与复制

日期事项可直接拖动卡片到其他分组。待办卡片或拖动手柄可放入其他文件夹列、左侧文件夹或另一个象限；项目卡片及手柄可放到左侧目标文件夹。移动保留原ID、日期、提醒、备注和关联，目标文件夹的重名规则继续生效。

拖动时卡片跟随鼠标，目标组显示主题色边框，靠近滚动区边缘时自动滚动。放下后保存，原有组内手柄排序保持；日期事项及待办保留各列浏览位置。

待办详情的名称、所属文件夹、截止日期、状态、备注和下一步支持选中复制，保持只读。统计记录详情同样支持复制；日期事项及项目编辑窗口的文本输入可直接复制。文字沿用原有字号、配色及浅深主题。

## 心情记录

心情选择采用两行、每行三种：兴奋、愉快、平静、疲惫、低落、烦躁。图标使用统一的彩色矢量表情，选择器、日期月历、当天详情及心情桌面组件保持一致；选择后用对应颜色的描边和浅色背景标明。

兴奋为黄色、愉快为橙色、平静为绿色、疲惫为灰棕色、低落为蓝色、烦躁为紫色。趋势图按感觉区间排列，圆点使用当天心情的颜色，悬停显示具体名称。只选择心情也可保存，文字可留空，原有记录及复盘文字继续保留。

## 每日记录与图片

心情与复盘可切换“月视图／每日记录”，选择会保存。每日页展示日期、表情、感受和图片，空白文字段落收起；投入和完成情况放在可展开的摘要中。每日模式左右按钮切换一天，月视图左右按钮切换一月。

月历按窗口高度调整，图片数量在日期角标中展示。图片可点击查看大图。每日页文字支持选中复制，编辑仍通过“编辑这一天”进入。

编辑窗口提供“添加图片”“粘贴图片 · Ctrl+V”和“本地图片”。添加时复制文件，粘贴时保存PNG，位置为当前用户数据目录下的`reflection-images`；原文件保留。取消编辑会清理本次未保存的副本，从记录移除图片需要确认，尚未保存的改动不会覆盖记录。只有图片也可保存，图片随本地备份打包，恢复后改写为新的本地路径。

## 习惯日视图与交互

目标与习惯加入日视图，切换日期后直接在卡片补打卡，撤销需确认。宽窗口双列、窄窗口单列，卡片使用30圆角及完成色块，展示累计天数和连续计划日；目标、周月年日历及统计同步更新。

拖动预览使用系统鼠标屏幕坐标转换到窗口内容区，预览绘制限制在内容区。横竖滚动条使用约3像素可见线，鼠标移入或拖动期间显示，移开后隐藏；透明操作区域保留，交汇角保持透明。底部默认的“选择一个项目，开始这一刻。”已去掉。

## 验证

工作区预览使用独立测试数据，覆盖不同尺寸、浅深主题和折叠导航。分组专项验证覆盖旧日期数据、新建空组、改名、删除保留事项、备份恢复、范围记忆、完成项折叠、完整卡片滚动、编辑返回位置和项目选择及排序。

分组预览位于`artifacts/qa/groups-*`，其他页面预览位于`artifacts/qa/refresh-*`。测试在独立后台桌面运行，保持活动桌面不变。
