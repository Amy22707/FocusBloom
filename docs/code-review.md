# 账号与同步代码审查

日期：2026年10月24日

## 范围与结论

审查覆盖本轮桌面账号界面、姓名与头像、密码登录和修改、账号切换、完整本地迁入、专注记录与偏好同步、浏览器扩展、PostgreSQL同步函数、月历滚动及打包配置。包括工作区修改与新增源码，未发现尚待修复的阻断问题。

## 关键行为

- 登录后的桌面与扩展隐藏登录表单，显示个人资料和独立退出入口；侧栏账号入口随姓名、头像更新，收起导航后仍可使用。
- 密码通过邮箱二次验证设置或修改，密码登录使用CloudBase约定的邮箱到`username`映射。密码仅用于本次请求，成功后清空输入，不写入资料缓存或同步记录。
- 已验证的资料和密码输入在刷新令牌前固定本次提交内容。个人资料服务暂时不可用时，已完成的数据同步仍更新状态，保留本机资料显示。
- 登录、验证码和令牌刷新请求不附带Authorization；访问个人资料和同步数据时才传入当前用户令牌。过期会话自动刷新后保存新令牌，刷新失效时提供中文重新登录提示。
- 登录失效后清理凭证、停止自动同步并显示未登录和重新登录横幅；保留当前账号本机资料，计时不中断，重新打开软件仍可查看原内容。临时网络失败不改变登录状态。
- 扩展认证HTTP请求在计时队列外执行，慢验证码请求不阻塞到期结束和解除限制。认证返回后再次检查计时状态，专注或休息期间不切换账号。
- 扩展重新登录保留云端已有偏好，包括桌面的番茄模式；账号切换期间返回的旧同步响应不能写入新资料。
- 桌面切换账号或准备导入时停止当前账号的自动同步，在重启后使用对应数据库重新开启；旧窗口等待退出期间不上传访客资料到新身份。
- 本地迁入保留全部已保存业务内容、关联、分组与偏好，重复导入不增加同ID条目。已有账号条目、同步游标及当前账号资料保留；显式导入前备份，并在旧窗口保存完布局后应用。
- 同步仅发送允许的项目、有效专注记录和通用偏好。心情、照片、待办正文及本机路径不进入同步请求。记录满10秒计入，原始暂停区间保留；记录按ID去重。
- PostgreSQL函数使用验证后的账号身份、按账号分配版本、事务提交和分页依赖。客户端不能直接访问同步表；匿名请求不能执行同步函数。
- 发布配置只包含客户端Publishable Key。开发配置、数据库、用户素材和构建产物保持在Git排除范围；SMTP授权码只配置在云端。
