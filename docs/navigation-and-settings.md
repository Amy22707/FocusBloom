# 导航与设置

日期：2026年10月16日

## 导航展示

在“偏好设置 → 导航展示与顺序”勾选要显示的栏目，拖动右侧手柄调整顺序，也可点击手柄使用前移／后移／移到最前／最后菜单。选择立即生效，关闭软件再打开仍保留。设置入口始终可见并可排序；学习浏览器继续从专注页进入。

导航展示与工作页面分开管理，调整顺序或隐藏栏目保持计时和记录归属。隐藏专注入口后仍可从待办等流程进入专注。当前页面在较矮窗口的导航区自动滚入可见位置；导航收起为图标的偏好保留。

收起后的图标居中显示，侧栏为滚动条保留空间；短窗口滚动时，各入口图标保持完整可见。展开后恢复左对齐的图标与名称。

默认顺序将偏好设置放在最后；已有配置中补入的新栏目放在设置前，其余已保存顺序保留。首次打开直接显示专注页；如果已隐藏专注入口，则显示第一个可见栏目。

## 设置分组与搜索

设置分为导航展示与顺序、外观与配色、事项块大小、计时与番茄、桌面计时浮窗、专注字体、专注图文与声音、日历与软件提醒、严格模式规则。分组首次默认折叠，点击展开；手动折叠和展开分别保存，下次打开恢复。背景／文字／声音内部原有的折叠偏好继续保留。

顶部搜索支持字体、颜色、背景、音乐、提醒、黑名单等关键词，也支持空格分开的多个关键词。匹配组会自动展开，不匹配组隐藏；清空搜索后恢复已保存的分组状态。没有匹配项时显示提示。搜索自动展开不会改写用户保存的折叠偏好。

设置滚动位置、事项块大小与实时预览保持。退出按钮仍可从设置底部访问。

## 图表悬停

年度热力图日期格及投入趋势／活跃时间柱，鼠标悬停约0.1秒自动显示日期或时段、总专注时长和结束次数；时长使用小时:分钟:秒，保留不足一分钟的细节。提示可停留30秒，适配当前配色及明暗主题，点击图形仍打开对应明细。

## 保存与验证

导航配置保存于`ui.navigation.items`，设置分组保存于`ui.settings.expanded.*`。`NavigationViewModel`管理展示顺序，主窗口按稳定页面标识导航；主Tab页顺序保持，计时、浏览器和全屏入口仍使用既有页面。

4项独立界面检查通过：导航勾选／排序／重开／计时连续性，实际鼠标悬停自动弹出及秒级内容，设置搜索／折叠／重开、滚动与预览，以及不同窗口高度下的导航底部间距。预览位于`artifacts/qa/settings-folded-sections.png`、`settings-search-fonts.png`、`settings-navigation-dark.png`及`statistics-hover-*`。
