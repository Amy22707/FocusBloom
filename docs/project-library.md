# 文件夹与项目管理

日期：2026年10月13日

项目库左侧“新建文件夹”和右侧标题旁“新建项目”打开简洁弹窗。新建项目默认采用当前文件夹，也可选择其他文件夹；名称为空或重复时在弹窗提示，创建成功后收起弹窗。列表不再常驻名称输入框，保留更多展示空间。

在“项目库”中，点击文件夹或项目旁的“···”，打开修改窗口。文件夹可改名；项目可修改名称、选择所在文件夹。保存后项目库、计时项目选择及记录中的项目名称同步更新，重开软件保留修改。

“这次，专注什么？”沿用上一次选择的文件夹与项目，选择后立即在本机保存，重开恢复。项目按 ID 记忆，改名或移动后仍能找到原项目；项目已删除时选择原文件夹中可用的项目，原文件夹也已删除时选择其他可用文件夹。上次明确选择空文件夹时继续显示该空文件夹。尚未保存过选择的已有用户，优先采用最近一条专注记录中的可用项目。

项目卡片每行三张，高度统一为120像素，按可用宽度排列；同一窗口下，1个、3个或7个项目保持相同尺寸。卡片从顶部紧凑排列，名称过长时省略并可悬停查看，不因数量少而拉高。

文件夹和项目旁的淡色“≡”是排序手柄，没有底色或边框。拖起后卡片预览跟随鼠标，原卡片淡化，其他项目平滑移动让出位置；靠近列表上下边缘可滚动。松开后保存顺序，取消拖动恢复原位。点击手柄也可选择前移、后移、移到最前或最后。顺序保存在本机，计时页下拉框沿用同一顺序；排序保持当前选择和计时，改名保持位置，新建项目追加到末尾。

文件夹名称不能为空且不能重复，同一个文件夹内的项目名称不能重复，不同文件夹可以有同名项目。新建、改名和移动均检查重名，比较时忽略名称首尾空格和英文大小写；保留原名称保存不算重名。每个项目由独立 ID 关联专注记录。移动项目保留原文件夹，即使其中已没有项目。

修改窗口提供“删除”按钮，点击后确认删除。删除项目从项目库及计时选择中移除；删除文件夹同时移除其中所有项目，确认提示会显示项目数量。历史专注记录、原项目关联与有效时长保留。正在专注或暂停的项目，以及记录尚未保存的项目，先结束并保存后再删除；包含这些项目的文件夹也需等待处理完成。

文件夹只剩一个项目时仍可删除该项目，删除后保留空文件夹，重开仍为空。正在计时、暂停或记录未保存时点击删除，只显示说明和“知道了”，提示窗口不提供删除按钮；结束并保存记录后，再次点击删除才显示正常的删除确认。

项目正在计时时可以改名或移动，计时继续归属同一项目 ID。修改不重置计时、不创建新会话、不改变当前图文。删除全部文件夹后，可继续新建文件夹与项目。

本机 SQLite 为项目保存删除状态，已删除项目不再加入活动项目列表，重开不会重新出现。已有数据库自动补充对应字段，专注记录保留外键关联。
