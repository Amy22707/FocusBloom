# CloudBase PostgreSQL 配置

日期：2026年10月24日

## 环境与邮箱

使用上海`ap-shanghai`的PostgreSQL环境。身份认证中开启邮箱验证码登录，配置邮件代发或自有SMTP。已创建的环境及邮箱配置继续使用。

邮箱密码登录还需要在身份认证的登录方式中开启“用户名密码登录”。客户端仍输入邮箱，无需另建用户名。品牌发件名称、标题与正文见[验证码邮件配置](branded-email.md)。

客户端只使用Publishable Key；管理员API Key、腾讯云SecretId／SecretKey及SMTP授权码不写入客户端。复制根目录的[配置示例](../cloudbase.example.json)，填写环境ID及Publishable Key，保存为`cloudbase.local.json`后运行：

```powershell
./scripts/configure-cloud.ps1
```

脚本检查客户端密钥角色及所属环境。构建会将配置复制到程序和扩展目录；本机开发配置不随Git提交。

## 在 SQL 编辑器部署

1. 进入现有环境的“SQL 型数据库”，确认页面显示“PostgreSQL 管理”。
2. 点击第二栏的“SQL 编辑器”，新建一个SQL查询。
3. 打开[PostgreSQL初始化脚本](../cloud/postgresql/setup.sql)，复制全部内容，粘贴到SQL编辑器中。
4. 点击“运行”，执行整份脚本。脚本可重复执行，保留现有同步记录，不修改邮箱账号或其他业务表。
5. 成功后，`public`下会出现`focusbloom_sync_state`、`focusbloom_sync_documents`两张表，以及`focusbloom_sync`函数。

也可运行`./scripts/package-cloud.ps1`生成便于复制的部署脚本。初始化脚本已经创建索引与权限，不需要在可视化页面逐个添加字段或索引。

## 权限与接口

两张同步表启用RLS，匿名和登录用户均不能直接读写。只有已登录的邮箱用户可调用同步RPC；函数从CloudBase验证后的JWT取得用户ID，在同一事务内处理本人的版本、记录和设置。

接口为：

```text
POST https://<环境ID>.api.tcloudbasegateway.com/v1/rdb/rest/rpc/focusbloom_sync
Authorization: Bearer <登录用户令牌>
Content-Type: application/json

{"p_cursor": 0, "p_changes": []}
```

参数不包含用户ID或管理员密钥。函数按账号锁定版本，重复上传不会增加记录；冲突内容返回客户端选择。下载分页会同时提供记录对应的项目，避免项目改名后遗漏关联。

## 登录与联调

桌面在“偏好设置 → 账号与同步”登录，扩展在“偏好设置 → 账号与同步”登录同一邮箱。桌面可选择合并访客全部已保存内容与偏好，包含待办、日期事项、课程、目标习惯、打卡、心情日历、字体和媒体配置；扩展合并访客专注记录与通用偏好。访客原数据保留。

已登录的桌面账号可点击“导入本机原有数据”，补入访客内容并应用访客偏好。账号已有条目保留，导入前自动备份账号数据库，完成后重新打开软件。本机素材沿用本机文件，云端同步范围不变。

左下角账号入口显示姓名和头像，点击可编辑资料。登录后隐藏验证码表单，在账号设置中单独退出登录。密码设置及修改通过当前邮箱二次验证；密码登录与验证码登录可切换，密码不写入本地数据库。姓名和头像通过身份认证接口保存，不需要修改同步表或重新执行SQL。

访问令牌正常到期后自动刷新。若登录凭证确实失效，桌面横幅及账号页提示重新登录，左下角显示“未登录”；扩展同样显示重新登录入口。失效凭证会清除，原账号本机数据仍保留在当前资料中，计时继续；重新登录同一邮箱恢复同步。普通断网不会被视为退出登录。

点击“立即同步”，确认成功后，在桌面完成一段至少10秒的专注，再到扩展同步并查看“记录”，反向同样验证。登录后首次同步，其后每隔七天检查一次云端。本机可同步的变更合并约两分钟后自动发送；“立即同步”不受周期限制。同一批失败的变更保留在本机，等下次手动同步、新变更或每周检查再试。

若提示“同步接口尚未部署”，确认整份SQL已执行成功并稍后重试；若SQL执行失败，保留错误文本以便定位。此部署使用数据库RPC，不上传云函数ZIP，也无需新建文档型集合。

## 数据范围

桌面和扩展共用基础接口，同步项目名称与分类、有效专注记录及原始区间、网站黑白名单与限制方式、通用计时偏好。插件拦截次数显示未统计。

运行新版 SQL 后，桌面另用 `focusbloom_sync_workspace` 同步工作区内容：项目目标、截止日期与里程碑，待办正文、分类、文件夹和提醒偏好，专注成果与关联待办，日历安排、日期事项、课表与调课，目标、习惯与打卡，心情和文字复盘。浏览器扩展继续使用基础接口。照片、封面、本机应用及媒体路径、窗口和组件布局保留在本机。

各账号与访客的本地数据分别保留；退出账号不删除账号副本。两端修改同一条资料时可选择保留本机或采用云端。Windows 登录凭证由当前用户加密，浏览器凭证保留在扩展本地存储，不随数据库备份导出。

接口依据：[PostgreSQL RPC](https://docs.cloudbase.net/en/database/postgresql/http/rpc)、[PG身份认证](https://docs.cloudbase.net/authentication-v2/auth/auth-pg)、[数据库函数](https://docs.cloudbase.net/database/postgresql/functions)。
