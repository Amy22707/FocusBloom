# 严格专注与学习浏览器

日期：2026年10月10日

严格模式在专注及暂停期间限制应用和网站，用户始终可以结束。休息、结束和退出解除限制。

## 使用

1. 在偏好设置的“严格模式应用与网站规则”中分别选择应用及网站的黑名单或白名单。白名单仅允许列表内，黑名单仅限制列表内。
2. 添加应用程序与网站域名，选择域名规则是否包含子域名。两种模式的列表分别保存，空白名单限制普通网站，空黑名单不限制普通网站；现代 Windows 应用建议从“选择运行中的应用”添加真实程序路径。
3. 在专注页选择严格模式并开始。当前会话采用开始时的模式与列表快照，编辑后的规则在下一次专注采用。
4. 从计时界面的“学习浏览器”进入并访问允许网站，可使用浏览器自己的全屏按钮，切换保留当前网页；“返回计时”回到当前专注。登录跳转或嵌入页面需要另一个域名时，将该域名加入下一次专注的白名单。
5. 点击结束或进入休息后，阻止界面关闭，应用及网站恢复正常操作。

## 实现

- 前台应用按程序路径识别，系统界面与软件自身自动放行。UWP 宿主窗口识别实际子进程。
- Windows 截图工具及截图浮层始终放行，支持截取学习内容。照片查看器按所选应用规则处理。
- 阻止界面覆盖目标屏幕并取得焦点，显示返回／结束入口；受限窗口状态和后台进程保留。
- “返回专注”先激活专注窗口，再隐藏阻止界面，一次点击完成返回。前台事件按处理时的实际前台窗口判断；返回后切换受限应用仍正常拦截。
- WebView2 主导航、重定向、新窗口和已打开页面接受相同域名检查；图片、样式、脚本和接口不作为阻止目标。
- 浏览器工具栏采用顶部标签页、紧凑导航与地址栏布局。“返回全屏／返回计时”以主色突出，“打开”位于地址栏内；浏览器全屏切换为小图标，保持原有网页和标签页。
- 弹窗共用 WebView2 环境和登录状态，进入标签页；暂停保持限制，结束恢复被阻止的页面。
- 本机保存黑白名单规则和浏览器登录状态，专注记录保存严格标记，历史普通记录保持可读。

## 验证

自动验证覆盖严格暂停、结束／休息释放、域名及子域名、空列表、外部浏览器默认受限、会话快照、旧数据库升级和严格记录保存。

WebView2 使用临时本地站点验证真实导航、已有标签页、重定向、允许／禁止弹窗、暂停限制及结束恢复，同时验证非白名单资源域名上的图片正常加载。测试使用单独浏览器目录，保留个人登录状态。

原生窗口验证使用专用临时窗口，确认阻止窗口取得前台焦点、受限窗口保持位置和非最小化状态，并且后台计数任务继续。监测钩子初始化和销毁通过验证。全局应用拦截仍需按下述桌面场景实测。

独立临时进程验证单次返回专注、返回后收到旧前台事件不重弹、再次切换受限窗口继续拦截，以及原窗口位置和非最小化状态保持。

## 桌面实测与当前边界

短时严格专注先将开发工具和测试工具加入白名单，再检查：允许应用可操作；切换记事本等受限应用进入阻止界面；暂停继续限制；点击结束解除；后台任务保持运行。另行验证提升权限窗口、独占全屏、多屏及窗口恢复行为。

Edge／Chrome 独立扩展提供自己的计时与网站黑白名单，直接加载使用。桌面严格模式仍按应用规则放行或限制外部浏览器；内置学习浏览器直接执行桌面网站规则。两端分别保存列表与会话。插件安装与使用见 [独立浏览器扩展](browser-extension.md)。
