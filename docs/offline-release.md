# 一刻专注 · FocusBloom Windows 离线版

一刻专注把待办、专注计时和每日复盘放在一起。核心功能可离线使用，无需注册账号。

## 开始使用

1. 双击 `FocusBloom-Windows-x64.msi`，按向导选择安装位置和是否创建桌面快捷方式。使用 ZIP 便携包时，完整解压到有写权限的目录。
2. 在安装完成页选择启动 FocusBloom，也可以稍后从开始菜单打开。使用 ZIP 时，双击解压目录中的 `FocusBloom.exe`。
3. 在「项目库」创建项目，或在「待办事项」创建任务并从任务开始专注。结束后可在「专注记录」查看投入时间、补记成果和下一步。

本包面向 **Windows x64**，包含 .NET 桌面运行时。安装包尚未签名，Windows 可能显示发布者提示。内置学习浏览器需要 Microsoft Edge WebView2 Runtime，访问网页及打开外部来源链接需要网络。

## 能做什么

- 正计时、倒计时和番茄循环，支持暂停、休息、中断恢复、全屏与置顶计时窗。
- 项目目标、截止日期、里程碑和项目预设；待办子任务、项目进度、四象限、专注成果和恢复备注。
- 日历、可归档和切换的多学期课表、CSV 课程导入、日期倒数、系统提醒及 ICS 导出。
- 专注统计、目标与习惯打卡、心情日历、图文复盘和桌面小组件。
- 自定义计时背景、文字与声音；可选应用和网站限制。

专注中文默认使用系统楷体，可在「偏好设置 → 专注字体」分别选择中文、英文和计时数字的字体，并调整专注画面字号。「偏好设置 → 软件字体」单独调整页面标题、导航与界面文字的字体和字号。「外观与配色」提供跟随系统、浅色和深色，默认跟随系统。背景库中的「湖畔暮色」和「雨窗书桌」可手动选择，不参与随机。

在普通或全屏专注画面右上角点相机，可把当前计时、句子与背景保存为 PNG。导出的画面隐藏操作按钮，保存位置会在窗口顶部提示五秒。备份和截图的保存目录可在「偏好设置 → 数据备份与恢复」分别选择，未指定时使用本机资料目录下的默认文件夹。

「偏好设置 → 语言」默认使用简体中文，选择 English 并保存后，重新打开软件可使用英文界面。你创建的项目、笔记和摘录保留原文。

在「项目库 → 新建项目」可用预设生成关联待办。待办详情可以勾选子任务，子任务完成不自动完成主待办。打开项目编辑器可查看累计投入、剩余预计和未安排的待办。

侧栏「计划本」提供独立的日、周、月清单。用日期框、左右箭头或右侧月历翻看历史和规划未来，勾选后自动保存。周计划可以按天拆分，月计划可以按周拆分。用事项右侧的铅笔按钮修改文字，用专注按钮选择计时方式和项目。专注名称会显示在计时页和历史记录中。事项旁的时钟按钮可以查看对应的专注历史。删除事项前需要确认，已经保存的专注记录会保留。

在「日历与课表 → 课程管理 → 学期管理」新建或切换学期。当前学期显示在课表中；切换会归档原学期的课程、节次和调课，归档学期不再安排提醒，切回即可继续查看和编辑。

本版不启用账号注册、登录和云同步，不附带独立浏览器扩展。软件的计时、任务和统计数据保存在当前 Windows 用户的本机资料目录。

## 备份、更新与退出

- 在「偏好设置 → 数据备份与恢复」导出 `.fbbak`。手动和自动备份均包含自定义背景、声音、句子和复盘照片。更换电脑时可在同一页面恢复。
- 点击窗口关闭按钮会缩到托盘，计时继续。彻底关闭请右键托盘图标选择「退出」。
- 在「偏好设置 → 关于」检查更新。MSI 安装版可确认下载，软件保存记录并退出后打开安装程序。便携版可从下载页取得新 ZIP，退出旧版后完整解压。程序文件夹和本机资料分开保存。
- 想在同一台电脑试用而不使用日常资料库，可以在解压目录的 PowerShell 中运行 `.\FocusBloom.exe --data-dir "$env:TEMP\FocusBloom-离线试用"`。
